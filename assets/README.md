# karez brand assets

Everything here is generated by [`scripts/brand/build_icons.py`](../scripts/brand/build_icons.py)
from one geometry definition, measured from the first Gemini master
(`docs/brand/reference/karez-k-solid-v1.webp`). Change the script and rerun it; do not edit the
files by hand.

```bash
python scripts/brand/build_icons.py          # SVG files only
python scripts/brand/build_icons.py --png    # also PNG and ICO (needs Microsoft Edge and Pillow)
```

Colours: amber `#F59E0B`, cyan `#22D3EE`, navy `#0A1020`.

## Files

| file | what it is | use it for |
|---|---|---|
| `svg/karez-mark.svg` | colour K with the stream, transparent | README header, docs, slides, anything 128 px and up |
| `svg/karez-mark-small.svg` | same mark, thicker stream and fan | favicons and any size below 128 px |
| `svg/karez-mark-white.svg` | single colour, white | dark banners and footers |
| `svg/karez-mark-dark.svg` | single colour, navy | light pages and print |
| `svg/karez-mark-amber.svg` | single colour, amber | docs site header |
| `svg/karez-tile.svg` | rounded navy app tile with an amber border | app icon, package registries |
| `svg/karez-avatar.svg` | square navy, K centred | GitHub organisation avatar (GitHub crops it to a circle) |
| `svg/karez-avatar-circle.svg` | circular navy with an amber ring | places that do not crop |
| `png/karez-mark-512.png` and the `-white`, `-dark`, `-amber` versions | transparent PNGs of the above | places that do not take SVG |
| `png/karez-tile-1024.png` | the tile | app icon |
| `png/karez-avatar-500.png`, `png/karez-avatar-circle-500.png` | avatars | organisation and registry avatars |
| `png/apple-touch-icon-180.png` | opaque navy square | iOS home screen |
| `png/favicon-16.png` to `png/favicon-512.png` | the small mark at 16, 32, 48, 64, 128, 192 and 512 px | favicons and web manifests |
| `favicon.ico` | 16, 32, 48 and 64 px | the classic `/favicon.ico` |

## Favicon snippet for the website

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/assets/svg/karez-mark-small.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/assets/png/apple-touch-icon-180.png">
```

## Notes

- The marks have true transparent backgrounds. The amber and cyan pair reads on dark pages. On a
  white page the cyan stream is lighter, so for light pages prefer `karez-mark-dark.svg` or put the
  mark on a navy tile.
- The stream is a gap cut through the K, not a separate shape, so the single-colour versions
  keep the channel.
- The wordmark, the social image and the logo lockup are generated separately with Gemini; see
  `docs/brand/gemini-prompts.md`.
